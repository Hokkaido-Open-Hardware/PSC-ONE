# PSC-ONE

PSC-ONEは、FPGA上のRISC-V CPU、メモリ、周辺回路、AIアクセラレータ、PSC-OSを一体で開発するプロジェクトです。

[English overview](README.md) · [ドキュメント一覧](docs/README.md) · [PULP命令拡張](docs/cpu_pulp_JP.md)

## なぜPSC-ONEを作るのか

AIは急速に私たちの生活へ入り込んでいます。

音声認識、画像認識、翻訳、文章生成。

今やAIは特別な研究設備ではなく、誰もが利用する時代になりました。

しかし、そのAIがどこで動いているのかを意識したことはあるでしょうか。

多くの場合、私たちが利用するAIは巨大なクラウドサーバの中で動いています。

- どのようなモデルが使われているのか
- どのようなデータが送信されているのか
- どのような処理が行われているのか

利用者が内部のモデルや処理を確認できない場合もあります。便利なサービスを使うだけでなく、内部を理解し、自分で変更できる環境を作りたいと考えています。

## 自分だけのAIを持つ

私は、

**「自分のポケットの中に、自分だけのAIを持ちたい」**

と考えました。

- インターネット接続がなくても動くAI
- 自分で作ったAI
- 自分で学習させたAI
- 自分で改造できるAI
- その中身をすべて理解できるAI

スマートフォンで十分だ、という考えもあるでしょう。

確かにスマートフォンは高性能です。

しかしスマートフォンは完成品です。

既製のスマートフォンでは、CPUやAIエンジンを自分で設計し直すことは容易ではありません。PSC-ONEでは、利用するだけでなく設計することを目指します。

## PSC-ONEの目的

対象はCPUコア、AIアクセラレータ、SDカードインターフェース、メモリコントローラ、LCD制御回路、OSとアプリケーションです。

そのすべてをオープンソースで公開し、自分自身で設計・理解・改造できることを目指しています。
